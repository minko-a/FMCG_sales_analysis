# FMCG Sales & Supply Chain Analysis

Business-oriented sales analytics project based on simulated FMCG data

## Project Goals
- analyze revenue trends
- evaluate promotion effectiveness
- identify seasonal sales patterns
- analyze inventory turnover and stock shortages

## Tools
- Python
- pandas
- matplotlib
- Jupyter Notebook

## Main Insights
- promotions increased average sales by ~95%
- sales activity was higher during mid-year periods
- Yogurt products showed the highest inventory turnover
- delivery delays were not strongly related to understock situations

Dataset was taken from: https://www.kaggle.com/datasets/beatafaron/fmcg-daily-sales-data-to-2022-2024/data
